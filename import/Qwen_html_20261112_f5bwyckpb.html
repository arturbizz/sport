Пустое окно справа — это боковая панель. Убираем за секунду.

Справа в Таблицах живёт служебная панель: Keep, Задачи, Календарь или дополнение. Иногда она открывается пустой и возвращается после каждой перезагрузки. Ниже — живая копия вашего интерфейса, где можно потренироваться, и разбор двух причин, почему панель не уходит.

Потренироваться в демо Почему возвращается?
3 способа закрыть 2 причины возврата данные не затрагиваются

Быстрый ответ

Нажмите стрелку «›» в самом низу справа — под иконками Календаря, Keep и Задач. Она сворачивает всю боковую область: и пустую панель, и полосу иконок.

Закрыли один раз — состояние запомнится для этого файла и аккаунта. Если панель всё равно возвращается — виновато дополнение или сбой, см. диагностику ниже.

Три способа закрыть панель

Все три работают в настоящих Таблицах. Начните с первого — он самый надёжный и убирает сразу всю боковую область.

Важно: состояние панели запоминается для связки «файл + аккаунт». Закрыли стрелкой или крестиком — после перезагрузки страницы панель останется закрытой. Если возвращается — это уже не «настройка», а дополнение или сбой (следующий раздел).

1Стрелка в правом нижнем углувсегда работает

Под полосой иконок (Календарь, Keep, Задачи…) есть маленькая стрелка «›». Нажмите — свернётся вся боковая область: и пустая панель, и сами иконки. Стрелка «‹» вернёт всё обратно. Это единственный способ, который работает даже когда панель пустая и без заголовка.

2Повторный клик по активной иконкеесли есть содержимое

Если панель открыта через иконку, иконка подсвечена синим кружком. Нажмите её ещё раз — панель закроется, полоса иконок останется. Работает для Keep, Задач, Календаря, Контактов, Карт и дополнений.

3Крестик в заголовке панелиKeep · Задачи · дополнения

У панелей с содержимым есть «×» в правом верхнем углу самой панели. Нажмите его — панель закроется. У пустой панели-сбоя заголовка может не быть вовсе: тогда поможет только способ №1 — стрелка внизу.

Если возвращается

Панель открывается снова после перезагрузки?

В норме закрытая панель не возвращается. Если возвращается — есть ровно две типичные причины. Ответьте на пару вопросов, чтобы понять, какая ваша.

Мини-диагностика

Причина 1 · Дополнение

Скрипт открывает панель сам при каждом запуске

  1. Откройте Расширения → Apps Script.
  2. Найдите функцию onOpen(e) и строку showSidebar(...) — именно она принудительно открывает панель при каждом открытии файла.
  3. Удалите или закомментируйте эту строку, сохраните проект (Ctrl+S).
  4. Не хотите править код: Расширения → Дополнения → Управление дополнениями → отключите или удалите дополнение.
  5. Файл чужой (как ваш «ОС --- Массовая проверка ИИ»)? Триггер живёт в скрипте владельца — попросите его убрать вызов, либо перенесите данные в новую таблицу без скриптов.
// Расширения → Apps Script — ищите это:
function onOpen(e) {
  var html = HtmlService.createHtmlOutputFromFile('Sidebar');
  SpreadsheetApp.getUi().showSidebar(html); // ← удалите строку
  // Если панель пустая — скрипт не отрисовал HTML,
  // но окно всё равно открывается при каждом запуске.
}
Причина 2 · Сбой загрузки

Панель не загрузилась и осталась пустой

  1. Обновите страницу: Ctrl+R (или F5).
  2. Откройте файл в инкогнито (Ctrl+Shift+N). Если там панели нет — виновато расширение браузера.
  3. Отключите блокировщики рекламы и скрипт-менеджеры для docs.google.com — они чаще всего ломают загрузку боковой панели.
  4. Очистите кэш и cookie для google.com за «Всё время», войдите заново.
  5. Проверьте в другом браузере и обновите текущий до последней версии.
